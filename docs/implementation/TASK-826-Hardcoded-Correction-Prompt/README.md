# TASK-826 — The durable correction node's prompt is a hardcoded Python literal

| Field | Value |
|---|---|

| **Type** | `bugfix` (configuration governance) |

## 1. The defect

`_CORRECTION_SYSTEM_PROMPT` (`apps/harness/src/harness/temporal/interpreter/nodes/consultation_realtime.py:561`,
used at `:663`) is a **Python constant**. `consultation.proposeCorrections` — the durable note-level
corrector — runs on it.

Its realtime sibling `agent.grammar`, added by TASK-815 Lane R, resolves a governed, approved,
version-pinned `PromptTemplate` through the node's `promptTemplateId` binding and **degrades visibly**
when unbound.

So two nodes performing the same class of work have opposite configuration postures, and the older
one violates the project rule: *"an engine name, model id, endpoint, credential, threshold, **prompt**,
taxonomy or label set is NOT a literal in code"* (`.claude/rules/00-project-context.md`
§Configuration Principles).

## 2. Why it matters beyond tidiness
A tenant cannot change how their notes are corrected, cannot review the instruction, and cannot pin a
version — while the *same capability* on the realtime lane is fully governed. A reviewer comparing
the two would reasonably conclude the platform's prompt governance is inconsistent, and be right.

## 3. What closing it requires
- Resolve the prompt through the same governed path `agent.grammar` uses (bound `promptTemplateId`,
  APPROVED, version-pinned), with **no in-code fallback** — an unbound or unapproved template degrades
  visibly rather than silently substituting a literal.
- Seed the platform-default template as a **SYSTEM-tenant** row, the sanctioned platform tier, as
  TASK-815 Lane N did for the findings and grounding instructions.
- A test proving a default fallback CANNOT creep back — Lane N's shape: adding one turns the
  "unbound instruction degrades and never falls back" test red.

## 4. Definition of Done
- [ ] `_CORRECTION_SYSTEM_PROMPT` deleted; the prompt resolves through the governed template path
- [ ] Platform default seeded as a SYSTEM-tenant `PromptTemplate`
- [ ] Unbound/unapproved degrades visibly; a mutation test proves no fallback can return
- [ ] Cross-language parity held; seeds regenerated by script
