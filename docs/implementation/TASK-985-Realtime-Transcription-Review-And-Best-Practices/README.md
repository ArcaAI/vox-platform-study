## 2. Current State Evaluation

### 2.1 The path end to end, with the load-bearing constants

**Browser capture and uplink (`@arcaai/vox`, `@arcaai/stt`).** `useArcaAudio.startAudio` opens the microphone with `getUserMedia({ audio: true })` unless a per-call `audioProcessing` is passed (`useArcaAudio.ts:561`), so the browser's own AEC/NS/AGC defaults apply; it does not use `@arcaai/room`'s `buildAudioConstraints`. It acquires the process-wide `AudioContextManager` singleton at 48 kHz (`:580`) and runs a 100 ms RMS meter with a 5 s silent-uplink watchdog (`:606-663`). The AudioWorklet coalesces 80 ms frames (`stt-capture.worklet.ts:36,67`), each decimated 48 to 16 kHz by a 97-tap Kaiser-sinc polyphase filter run per frame (`audioResampler.ts:229-247`), converted to Int16 (1280 samples, 2560 B) and sent as a binary WS frame (`SttWebSocketClient.ts:443-451`) unless `bufferedAmount >= 1 MiB` (`:178`). Frames while `!isConnected()` are discarded uncounted (`StreamingBackendSTTProvider.ts:321-323`). Session create carries `agentSlug` (or deprecated `pipelineId`), `sampleRate: 16000` (`STTProcessor.ts:788`), `language` and `languageMode` (`:282-284`), which default to `'en'` and `'auto'` from the store (`agenticStore.ts:405`, `useArcaAudio.ts:425,434`, `PluginManager.ts:665`). Reconnect: 5 attempts, 1 s to 30 s backoff, fresh single-use ticket, `{type:'resume', sessionId, lastSeq}` (`SttWebSocketClient.ts:279-282, 376-378, 823-827`). Stop: mic released, then `stopAndDrain` with a 1.5 s ceiling and a 250 ms quiet window after `finalizing` (`:187-189, 584-692`).

**Gateway session and WebSocket (`apps/api`).** `POST audio/transcription-jobs/stream/session` (`transcription-job.controller.ts:730-935`): uuidv7 id, entitlement concurrency gate on the socket-registry count, `AsrAgentResolverService.resolve` (no cache), `buildResolvedAsrSpec` folds `Agent.compiledConfig` with the primary row's `_metadata.asr` and exactly one fallback row (`build-resolved-asr-spec.ts:586-587`), STT `POST /internal/streaming/sessions` under the governed `sttStreaming.sessionCreateTimeoutMs` (60 000 ms, `stt-gateway.descriptors.ts:58`), then three Redis writes in one uncompensated `Promise.all` (`:880`). `WS /ws/stt/stream` (`stt-ws.gateway.ts`): ticket consumed, tenant and owner binding, `ready` emitted after handler registration (`:699-708`); each binary frame is one non-awaited `XADD stt:audio:{id} MAXLEN ~10000` with `final='0'` (`:1341`, `streamingAudioBridge.service.ts:277-300`). Results: a dedicated reader per subscriber on group `captions`, `XREADGROUP COUNT 100 BLOCK 500`, own PEL first (`:478-500`); relay drops partials and queues finals (limit 200) above `STT_WS_EGRESS_HIGH_WATERMARK_BYTES` (env, 512 KiB, `stt-ws.gateway.ts:96`); every message is seq-tagged into a 200-entry resume buffer (`:1118`). Disconnect starts a 15 s grace (`STT_WS_RESUME_GRACE_MS`, env, `:118`) then `finalizeSession('grace window expired')`, `interrupted = true` (`:1218`). `{type:'stop'}` writes `finalize` on `stt:control` (`:1292-1294`); only `{type:'close'}` or an auth failure closes the socket (`:1303-1308`). No ping/pong (`:308` is a count publisher only).

**STT ingestion and segmentation (`apps/stt`).** `IngestionConsumer` reads with group `stt-ingest`, `COUNT 100 BLOCK 5000`, XACK per batch, XAUTOCLAIM of its own pending at `min_idle 0` on the first pass (`redis_streams.py:377-433`); `XTRIM MINID` every 30 s (`session_manager.py:3256-3269`). `_on_frame` (`:3293-3349`) returns when status is not ACTIVE, appends to `audio_buffer` (500 MB cap) and the uncapped `processed_audio_buffer` (`:3303`), then `preprocessor.feed`. The preprocessor peak-normalizes each 32 ms frame against a 3 s peak window floored at 0.05 (gain ceiling 20x, `preprocessor.py:61,66,351`), and, with VAD off, gates speech by energy: EMA noise floor capped at 0.015, threshold 2.5x floor, probability `rms / (2 x threshold)` (`:35,33,691-697`), onset at 0.6, offset below 0.45 after `min_silence` (profile literal 500 ms because the agent's vad block is read only when `vad.enabled`, `session_manager.py:510-524`, `execution_profile.py:161`), or earlier when the semantic endpointer sees terminal punctuation on the partial hypothesis and 200 ms of silence (`semantic_endpointer.py:203-219`, `dto.py:657`), or at `maxUtteranceSec 60` with 120 ms or 500 ms carry-over (`preprocessor.py:48,55`). Partials fire every `partialIntervalMs` (300 from the agent; module fallback 0.4 s, `:74`) once 0.5 s is buffered, carrying the last `partial_window_s` of audio (agent 3 s over the row's 6, `spec.py:779-782`), skip-if-busy (`session_manager.py:3161`).

**STT inference, decode and commit.** Finals go to a per-session queue (maxsize 64) drained by one loop; partials wait up to 2 s on the final-published gate (`:3168-3175`). `StreamingInferenceWorker` composes prompt = pair priming prompt (`language_modes.py:169-175`, module switch `:255` True) + agent `initialPrompt` + last 50 words of the previous final (`inference.py:855`, `dto.py:793`), and calls the adapter via `asyncio.to_thread`. `WhisperCppAsrAdapter` splits a final into 7 s spans cut at the quietest 30 ms frame (`whisper_cpp_asr.py:552-600`), takes one process-wide `threading.Lock` per model (`:429,465`), and calls `Model.transcribe` with `temperature=0.0, temperature_inc=0.0, language=None` (ml-en) and the same `initial_prompt` for every span (`:672-697`); nothing else is passed (no beam, thresholds, audio_ctx, flash_attn). An empty non-last span is retried once 250 ms shorter (`:107`). Post-decode on finals: hallucination gates (filler regex, RMS < 0.01 with <= 3 words), cadence-fast punctuation (CPU, 0.4 s time-box, `inference.py:1250`), disfluency, lexicon snap (the stage is built once per session and logs `stt.streaming.lexicon.configured` with `enabled`, `term_count`, `active`, `inference.py:175-188`; it turns ON whenever the resolved spec carries hotwords, `spec.py:752-757`). `LocalAgreementPolicy` marks `stable_chars` as the agreed prefix of the last two hypotheses; on a window slide it aligns by an exact normalized tail match or falls back to a timing estimate and freezes `min(anchor, len(committed))` (`commit_policy.py:265-273,319-322`). `EngineSwitchController` arms only on `CloudASRTranscriptionError` or `ModelError` (`engine_switch.py:52`) and holds one fallback id (`:99`). Models load by slug through the `ModelCache` from the s3fs mount, nothing warmed at boot (`main.py:90`), idle TTL `stt.modelCache.ttlSeconds` (default 600, clamp 60 to 3600), unpinned at `remove_session` (`session_manager.py:1755`).

**Deployment.** One `hope-stt` pod on the single k3s node, 2x RTX 2000 Ada time-sliced x3 (6 units, all allocated: LM Studio 4, STT 1, STT worker 1), image built with `GGML_CUDA=ON CMAKE_CUDA_ARCHITECTURES=89` (`apps/stt/docker/Dockerfile:291`), requests cpu 2 / 8Gi / gpu 1, limits cpu 8 / 24Gi, `OMP_NUM_THREADS=8`, weights over an s3fs sidecar with `HF_HUB_OFFLINE=1`, readiness on `/api/v1/health` (DB, MinIO, Redis; never model residency or draining), dev overlay `maxSurge 0 / maxUnavailable 1` (`overlays/dev/kustomization.yaml:306`), preStop `sleep 10` (`base/stt.yaml:174`). `build-stt` runs on every pipeline with no `changes:` rule (`.gitlab/ci/build.yml:509`). Batch worker: `dramatiq --processes 2 --threads 4` (`Dockerfile:465`) on the same cards.

**Consumers.** Scribe (`consultation-demo-screen.tsx`) through `useArca()` (whole-store subscription); Live Transcription playground through its own hook (`use-live-stt-session.ts`: 16 kHz context, no resample, stop then release then DELETE with no drain, `:410-423`); `@arcaai/vox-node` `RealtimeSttSocket`; `apps/example` raw demo (deprecated `pipelineId`, ScriptProcessor, box-filter downsample). Wire reference: `apps/admin-console/src/shared/docs/stt-socket-protocol.ts` (no `gap` frame documented).

## 5. Verification protocol

**Metrics (definitions).** `medical_wer`: word errors over reference words after the fixture normalizer, worst clip gated; `term_restricted_wer` (MedWER shape, F9-K4): errors on a fixed drug/diagnosis/symptom list, with 95 % bootstrap CI. `cer` (normalized and unnormalized): primary for Malayalam and code-switch (F9-E2). `keyterm_recall` / `keyphrase_recall`: fraction of `.keyterms.json` entries (synonym map, both scripts) present in the final transcript. `latin_ratio`: Latin letters over letters per final; assert per language mode. `first_partial_ms`: first partial receive time minus first audio frame send time. `commit_latency_ms`: receive time of a final minus send time of the frame containing its `endTime` (single monotonic clock, real-time pacing). `committed_revision_rate`: share of settled characters later changed, skipping `stableChars = 0` tails; `partial_flicker`: mean Levenshtein distance between consecutive partials of one utterance. `audio_coverage_ratio`, `seq_gap_count`, `tail_final_delivered` (last GT utterance present in `onTranscript` and `transcript.json`). §2.5 counters: `repeat_rate`, `echo_rate`, `fragment_rate`, `clause_break_rate`, `orphan_fragment_rate`, `article_digit_rate`, `terminal_on_fragment_rate`, `filler_token_rate`, `text_yield_wpm`, each with its reference-label rate recorded beside it. Serving: `session_create_ms` p95 (cold and warm recorded separately), `inference_latency` p50/p95 by engine and kind, `rtf` p95, `lock_wait_ms` p95, `model_resident`, `queue_dropped` and `script_mismatch` as ratios of `utterances_total`.

**Fixtures.** The three English clinical reads plus deterministic noise-augmented variants; a > 60 s continuous-speech clip; a silence-only and a room-tone clip; one real de-identified two-speaker WAV with forced-alignment turns; the 24 ml-en clips under `STT_MLEN_EVAL_DIR` (never in git); the owner's encounter audio; the committed 107 s Malayalam WAV only once its de-identification is confirmed.

**N and statistics.** N >= 5 runs per fixture on a quiet stack (`sessions_active = 0`, model warmed by a preceding session, no LM Studio load); gate on the median with 2xMAD, or on bootstrap CIs (B >= 1000, blockwise for streaming, F9-E3) where a baseline comparison is claimed. No epsilon is widened to fit a spread; a flaky gate is re-captured on a quiet stack.

**Environment control.** Every scorecard and every baseline entry carries the fingerprint of BP-1 (agent version, model slug and digest, geometry, prompt hash, vad state, engine build, device, SDK operating point). The harness opens the session exactly as the scribe does for one entry and exactly as the reference harness does for another. CUDA numbers come from the cluster; MPS numbers are labelled local and never promoted to a baseline.

**Gates and where they run.** Unit (CI `test-stt`, blocking): transcribe-kwargs per `InferenceConfig`; resolver tests (explicit empty hotwords, second fallback, unsupported knob sources); seed-geometry parity with the baseline fingerprint; drain and `ready` handling in both SDKs; lexicon dictionary sweep = 0; seam de-dup and repeat-guard unit tests. Live (nightly `stt-quality-gate` on the GPU runner, `RUN_INFRA_TESTS`, artifacts = scorecard JSONs; required manually on any seed `streaming.*` / `_metadata.asr` / prompt change): WS-gateway streaming scorecard (English + ml-en), loss harness incl. mid-clip close, stop-after-speech tail test, room-tone test, concurrency curve. Production (dashboard + alerts): the BP-5 series with RTF p95 > 0.8 for 10 m, any queue drop in 15 m, mismatch ratio > 5 % over 1 h, ttl evictions during clinic hours, session-create p95 > 1 s.
