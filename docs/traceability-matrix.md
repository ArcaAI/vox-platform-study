# HOPE Traceability Matrix

Last updated: 2026-07-04

Maps each business capability to the services, packages, data models, API routes, and tests that implement it. All route paths are verified against controllers/routers in code; gateway routes are relative to the global prefix `/api/v1`. Gaps are marked `—`.

Test location shorthand:

- **unit(app)** = `packages/applications/src/services/<svc>/__tests__/` · **unit(dom)** = `packages/domains/src/**/__tests__/` · **unit(api)** = `apps/api/src/**/__tests__/`
- **e2e** = `apps/api/tests/e2e/*.spec.ts` (Playwright) · **contract** = `tests/contracts/` · **x-tenant** = `tests/cross-tenant/` + `task-307-*` e2e suite
- **py(stt)** = `apps/stt-v2/tests/` · **py(smr)** = `apps/smr/src/smr_v2/tests/` · **py(grd)** = `apps/guardrail/src/guardrail/tests/` · **py(nlp)** = `apps/nlp/tests/` · **py(hrn)** = `apps/harness/src/harness/tests/`

## Known gaps / honest notes

- **Row 23 / 29 / 36**: service or schema exists without a public REST surface (eval, notifications/webhooks) or without any consuming service (FedL models). These are recorded as-is, not invented.
- The former `tests/contracts/tts.contract.test.ts` (targeting the removed `apps/tts` service) and its schemas were removed in TASK-414.
- The NLP k3s manifest (`deployment/k3s/base/nlp.yaml`) exists but is not registered in the base kustomization — NLP currently deploys only in dev/host setups.
- `apps/ui-playground` (deprecated) still consumes many of the admin surfaces above; no new capabilities should target it.
