### E) Typical DB/Orchestration Routes (No Direct HTTP Target)
Most routes under `/admin/*`, `/consultations/*` (CRUD/queries), `/users/*`, `/tenants/*`, `/auth/*`, `/storage/*`, `/workflows/*` (exposure plane uses HarnessGatewayService as above), etc. are handled by services in `packages/applications` using Prisma/Postgres, Redis, BullMQ, etc. **No external HTTP call** is made directly by those gateway routes/controllers in the common case. See [`inventory/routes.json`](../inventory/routes.json) for per-route details.

## Notes
- Downstream service URLs come from env/config: `TEXT_URL`, `STT_URL`, `NLP_URL`, `GUARDRAIL_URL`, `HARNESS_URL`/`HARNESS_BASE_URL`, `TTS_URL`, `LMSTUDIO_AGENT_URL`, MLflow URL, etc. (see [`apps/api/src/config/env.descriptors.ts`](https://github.com/ArcaAI/project-hope/tree/dev-2.2/apps/api/src/config/env.descriptors.ts), [`apps/api/src/common/gateway-http-agent.ts`](https://github.com/ArcaAI/project-hope/tree/dev-2.2/apps/api/src/common/gateway-http-agent.ts)).
- Internal service auth uses shared tokens (`INTERNAL_ACCESS_TOKEN`) sent as `X-Service-Token`; tenant header is `X-Tenant-Id`.
- The gateway does **not** proxy NLP/Guardrail/Harness via generic proxy routes — calls go through service clients or are made by other services.
