# 14. Gateway → Downstream Internal Calls (Source API → Target APIs)

**Sources:** [`apps/api/src/modules/*`](https://github.com/ArcaAI/project-hope/tree/dev-2.2/apps/api/src/modules), [`packages/applications/src/services/*`](https://github.com/ArcaAI/project-hope/tree/dev-2.2/packages/applications/src/services), [`apps/api/route-manifest.json`](https://github.com/ArcaAI/project-hope/tree/dev-2.2/apps/api/route-manifest.json)

> **Note:** Many gateway routes are DB/orchestration routes (Postgres via services in `packages/applications`) with **no direct HTTP target**. This section lists routes/controllers that make HTTP/WebSocket calls to downstream services or external providers, categorized with source→target mappings. Paths are relative to repo root; code references point to GitHub tree URLs.

## Quick Reference: Key Internal Tokens/Headers

- `X-Service-Token` / `INTERNAL_ACCESS_TOKEN` / `HARNESS_SERVICE_TOKEN` / `HARNESS_INTERNAL_SERVICE_TOKEN` — service-to-service auth (see [`apps/api/src/shared/base-proxy.controller.ts`](https://github.com/ArcaAI/project-hope/tree/dev-2.2/apps/api/src/shared/base-proxy.controller.ts), [`apps/api/src/modules/ai-inference/ai-inference.client.ts`](https://github.com/ArcaAI/project-hope/tree/dev-2.2/apps/api/src/modules/ai-inference/ai-inference.client.ts), [`packages/applications/src/common/internal-service-headers.ts`](https://github.com/ArcaAI/project-hope/tree/dev-2.2/packages/applications/src/common/internal-service-headers.ts))
- `X-Tenant-Id` — tenant context for internal calls
- `X-Request-Id` — request correlation
