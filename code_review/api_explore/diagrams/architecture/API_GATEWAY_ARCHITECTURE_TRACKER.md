## Batching rationale

A single diagram covering all 818 routes / 148 controllers / 77 modules would be unreadable. Work is split into **domain batches**. Each batch produces an Archify architecture candidate + finalized HTML focused on that domain’s endpoint → controller → service → downstream microservice/API flow. A **master overview** batch ties the batches together at gateway level.

## Status legend

- `PENDING` — not started
- `IN_PROGRESS` — being researched/authored
- `BLOCKED` — missing evidence, ownership, or dependency
- `REVIEW` — finalized artifact needs human/visual review
- `DONE` — finalized, gates passed, evidence recorded
