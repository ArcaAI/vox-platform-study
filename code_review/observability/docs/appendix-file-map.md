## Manifest map

| File | Creates | Notes |
|---|---|---|
| `01-rbac.yaml` | SA, ClusterRole, ClusterRoleBinding for Prometheus | Must include `nodes/proxy` for cAdvisor. Apply first. |
| `02-prometheus-config.yaml` | ConfigMap `prometheus-config` (scrape jobs + alert rules) | Rendered by Prometheus initContainer. Restart STS after edits. |
| `03-prometheus.yaml` | StatefulSet + Service `prometheus` | 50Gi PVC, `--web.enable-admin-api`. |
| `04-alertmanager-config.yaml` | ConfigMap `alertmanager-config` | v0.28 `matchers` syntax; `null` receiver by default. |
| `05-alertmanager.yaml` | StatefulSet + Service `alertmanager` | 10Gi PVC. |
| `06-grafana-provisioning.yaml` | ConfigMaps `grafana-datasources`, `grafana-dashboards-provider` | File-based provisioning at `/etc/grafana/provisioning`. |
| `07-grafana-dashboards.yaml` | ConfigMap `grafana-dashboards` (13 JSON files) | **Generated by `dashboards/generate.py`.** Restart Grafana. |
| `08-grafana-permissions.yaml` | Job `grafana-permissions-fix` | chowns the Grafana PVC for the `grafana` UID. |
| `09-grafana.yaml` | Deployment + Service `grafana` + 20Gi PVC | Mounts dashboards CM; file provider. |
| `10-ingress.yaml` | 3 Ingresses (class `traefik`) | `grafana-vox2`, `prometheus-vox2`, `alertmanager-vox2`. |
| `11-loki-config.yaml` | ConfigMap `loki-config` | tsdb v13, 720h retention, compactor. |
| `12-loki.yaml` | StatefulSet + Service `loki` | 50Gi PVC; ClusterIP only (no public exposure). |
| `13-promtail.yaml` | DaemonSet `promtail` + ConfigMap | Static glob `/var/log/pods/*/*/*.log` + CRI stage (no ClusterRole). |
| `14-loki-nodeport.yaml` | Service `loki-nodeport` (NodePort 31100) | LAN-only ingest for the GPU host. |
| `15-node-exporter.yaml` | DaemonSet + Service `node-exporter` | Our copy; 6 replicas (one per node). |
| `grafana-secret.yaml.example` | — | Template for the `grafana-admin` Secret. |

## Apply order (fresh install)

```bash
NS=project-hope-vox-infra

kubectl apply -f manifests/01-rbac.yaml
# create the secret first (copy 01 key from grafana-secret.yaml.example):
kubectl -n $NS create secret generic grafana-admin \
  --from-literal=GF_SECURITY_ADMIN_USER=admin \
  --from-literal=GF_SECURITY_ADMIN_PASSWORD='<pw>'

kubectl apply -f manifests/02-prometheus-config.yaml
kubectl apply -f manifests/03-prometheus.yaml
kubectl apply -f manifests/04-alertmanager-config.yaml
kubectl apply -f manifests/05-alertmanager.yaml
kubectl apply -f manifests/06-grafana-provisioning.yaml
kubectl apply -f manifests/07-grafana-dashboards.yaml
kubectl apply -f manifests/08-grafana-permissions.yaml
kubectl apply -f manifests/09-grafana.yaml

kubectl apply -f manifests/11-loki-config.yaml
kubectl apply -f manifests/12-loki.yaml
kubectl apply -f manifests/13-promtail.yaml
kubectl apply -f manifests/14-loki-nodeport.yaml

kubectl apply -f manifests/15-node-exporter.yaml
kubectl apply -f manifests/10-ingress.yaml
```

(`07` is produced by `python3 dashboards/generate.py`; the file is committed, so
applying it directly is fine.)
