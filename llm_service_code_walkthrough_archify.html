Key Concept for Your Walkthrough: Multi-Provider Egress & Unbreakable Streaming Hub

apps/text is the platform's multi-provider LLM brain. It enforces two non-negotiable rules: 1. "Killing the HTTP response never kills the producer" — streaming generations are detached background jobs owned by GenerationHub with an in-memory ring buffer (128 items) and batched Redis Stream flushes, allowing clients to disconnect and resume without restarting generation; 2. Strict Separation of Lanes — the internal LLM judge lane (/generate/internal/judge for Granite Guardian) runs on isolated semaphores with dedicated circuit breakers and zero rate limits, making safety checks immune to public user traffic exhaustion.

💡 Quick Presentation Takeaways (3 Bullet Points for Leadership)
🎯
1. Decoupled Generation Hub

Unlike standard FastAPI endpoints that crash when a clinician refreshes their browser, GenerationHub guarantees that dropped HTTP connections never terminate in-flight LLM compute. Dual-buffer replay ensures zero token waste on reconnect.

🛡️
2. Dual Safety Gates & Isolated Judge Lane

Clinical requests are verified before inference (prompt safety) and after inference (output toxicity & PII redaction). The safety judge lane operates on dedicated hardware semaphores so safety checks are never starved by high user traffic.

⚡
3. Dynamic Multi-Provider Routing (BYOK)

Zero models are hardcoded into environment variables. The API Gateway injects provider and credential metadata on every request, seamlessly routing between on-premise local GPUs (vLLM / LM Studio) and cloud LLMs (Azure OpenAI / Bedrock).
